1. EXECUTIVE SUMMARY & ARCHITECTURAL OVERVIEW
--------------------------------------------------------------------------------
The redundant full-screen branded `SessionVerificationScreen.tsx` (centered logo 
and spinner) has been completely removed from the refresh experience and replaced 
with a lightweight, neutral ERP shell skeleton (`ERPShellSkeleton.tsx`).

The ERP shell skeleton reuses CTVILL's existing skeleton components (`SkeletonBase`, 
`DashboardSkeleton`, `TableSkeleton`, `CardGridSkeleton`, `KanbanSkeleton`, 
`GanttSkeleton`, and `SiteDiarySkeleton`) and styling (`.skeleton-shimmer` pulse 
effects in `src/index.css`).

Key Guarantees:
1. Zero Full-Screen Loading Screen: No full-screen branded overlay or spinner 
   is rendered during session verification or page refresh.
2. Zero Landing-Page Flash: Public landing page and login portal are never 
   rendered while checking existing sessions.
3. Zero Data or Permission Leakage: Neutral shell skeleton contains zero 
   protected data, zero user details, and zero role-specific sidebar modules 
   until session validity and RBAC permissions are confirmed by `/api/auth/me`.
4. Pixel-Aligned Module Continuity: Content area of `ERPShellSkeleton` 
   pre-aligns to the requested module from the URL hash (e.g. `#gantt`, `#rfis`, 
   `#timekeeper-attendance`). Once authenticated, it transitions directly into 
   `AdminPortal` which continues rendering the active module skeleton while 
   `reloadAllData` completes, eliminating duplicate skeleton layers and layout 
   shifts.
5. Strict Security Preserved: HttpOnly session cookies, CSRF protection, 
   automatic session timeout (30 min inactivity), and vertical RBAC enforcement 
   remain 100% active.
