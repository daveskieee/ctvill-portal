1. ARCHITECTURAL SUMMARY & PROVIDER PRIORITY
--------------------------------------------------------------------------------
The manpower recommendation engine in CTVill Construction ERP has been upgraded
from a single-provider system to a resilient three-layer architecture:

  Layer 1 (Primary): Google Gemini (`gemini-3.1-flash-lite`) via @google/genai
    - Fast, cost-effective inference for commercial fit-out manpower reallocation.
    - 10-second request timeout via Promise.race.
    - Retry policy: Max 1 retry for transient 503/UNAVAILABLE; 0 retries for 429
      quota exhaustion or 401/403 auth errors to ensure immediate failover.

  Layer 2 (Secondary): Groq (`openai/gpt-oss-20b`) via official groq-sdk
    - Automatically engaged when Layer 1 encounters 429 quota exhaustion, rate
      limits, 503 high demand, timeouts, or unconfigured keys.
    - Verified model ID: `openai/gpt-oss-20b` (supported on Groq LPU platform).
    - 10-second request timeout.
    - Retry policy: Max 1 retry for transient 503/502; 0 retries for 429/401/403.

  Layer 3 (Final Fallback): Existing CTVILL Rule-Based Recommendation Engine
    - Model Identifier: `heuristic-v1`
    - Automatically engaged if both Gemini and Groq are unavailable, offline, or
      return zero valid candidate recommendations.
    - Generates 100% deterministic, valid recommendations derived directly from
      the ground-truth PostgreSQL commercial fit-out database.
