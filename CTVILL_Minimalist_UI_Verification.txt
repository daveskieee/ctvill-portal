3. CORE DESIGN IMPROVEMENTS IMPLEMENTED
================================================================================
A. Main Layout & Ergonomics:
   - Persistent, collapsible left sidebar with clean Lucide icons.
   - Grouped navigation by department (Executive, Engineering, Operations, Finance, System).
   - Clean top header with department breadcrumb (e.g. "Commercial & Financials > Payroll Ledger").

     and contractors with quick-jump navigation.
   - Notification popover with operational alerts, sound toggle, and dismissal actions.
   - Unified user profile button and sign-out controls.

B. Executive Dashboard:
   - 5 Compact KPI Summary Cards:
     1. Active Projects (count and target handover status)
     2. Total Active Workforce (on-site headcount from contractor logs)
     3. Pending Tasks & Defects (open engineering action items)
     4. Committed Budgets (sum of active project contract budgets)
     5. Disbursed Expenses (actual settled payroll disbursements)
   - Real Data Guarantee: All summary cards calculate strictly from actual PostgreSQL
     database records (projects, contractors, tasks, punch lists, payroll runs). Zero
     mocked, fabricated, or synthetic numbers.
   - Clean Visualizations:
     1. Milestone Progress Chart (Recharts BarChart showing real completion % by site).
     2. Budget vs Disbursed Cost Chart (Recharts BarChart comparing committed budget
        vs disbursed payroll expenses).
   - Recent Activities Ledger: Real audit log records displayed in a clean tabular view.
   - Operational Notices Panel: Real-time alerts for weather warnings, pending change
     orders, and open RFIs.
   - Commercial Fit-Out Sites Table: Dense overview of ongoing fit-out locations, status
     badges, progress bars, budgets, and direct project switcher links.

C. Module Pages:
   - Consistent layout pattern: Page Title, short descriptive subtitle, filters, search,
     and primary action buttons.
   - Data tables using clean borders, muted headers, and high-contrast readable cell text.
   - Standardized status badges (emerald for active/disbursed, amber for pending/progress,
     rose for critical/defects, slate for draft/idle).
   - Simplified modals and forms while preserving every single form field and input handler.

D. Visual Styling:
   - Backgrounds: Dark neutral slate (bg-slate-950, bg-slate-900).
   - Borders: Subtle structural borders (border-slate-800, border-slate-700/60).
   - Typography: Clean sans-serif hierarchy with tight, readable tracking.
   - Animations: Soft, performant transitions (transition-colors duration-150); eliminated
     distracting neon glowing animations, giant decorative card gradients, and heavy pulse effects.
